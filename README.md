# CodexQrLink - Professional QR Code Generator

🔗 **Generate QR codes instantly with a beautiful, modern interface**

## Features

✨ **Modern Design**
- Dark/Light theme toggle
- Responsive iPad & desktop optimization
- Smooth animations and transitions

🎨 **Smart Color Themes**
- 7 unique color palettes
- Automatic color assignment per URL (same URL = same color)
- One-click manual color switching

📱 **Easy to Use**
- Paste from clipboard with single click
- Type or paste URL directly
- Generate with button or Enter key
- Clear input button for quick reset

🚀 **Professional Features**
- Real-time QR code generation
- Displays encoded URL below QR code
- Toast notifications for user feedback
- Automatic HTTPS protocol detection
- Responsive across all devices

## How to Use

1. **Paste a Link**: Click the "Paste" button or paste directly into the input field
2. **Or Type**: Enter a URL in the input field
3. **Generate**: Click "Generate" or press Enter
4. **Done**: Your QR code appears instantly with auto-assigned color theme
